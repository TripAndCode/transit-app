# プライバシーポリシー

最終更新日：2026年10月28日

遅延ダッシュボード（以下「本サービス」）は、TripAndCode が個人で運営しています。このページでは、本サービスが扱うあなたの情報と、その扱い方を説明します。

- 氏名と住所：求めに応じて、遅滞なくお知らせします。

## 集める情報と使いみち

| 情報 | 集めるとき | 使いみち |
|---|---|---|
| メールアドレス、表示名、アイコン画像の URL | Google または GitHub でログインしたとき | 本人の確認、アカウントの表示 |
| ログインの記録（日時、方法、IP アドレス、ブラウザの種類） | ログインとログアウトのとき | 不正利用の調査、セキュリティの維持 |
| セッション（IP アドレス、ブラウザの種類、最後に使った日時） | 使っている間 | ログイン状態の維持、ほかの端末からのログアウト |
| 日ごとの利用回数（画面や API の種類ごとの回数とエラー数、見ていた事業者） | 使っている間 | 利用状況の把握、負荷の管理、料金の検討 |
| 保存したビュー、「質問」画面の調査 | あなたが保存したとき | その機能を提供するため |
| 「質問」画面の質問文（アカウントと結びつけない形） | 「質問」画面を使ったとき | 回答の品質の改善。運営者が質問の候補に採用したもの（よく使われる質問を自動で採用する場合を含みます）は、同じ事業者を見ているほかの利用者にも候補として表示することがあります |
| あなたが登録した LLM の API キー | 登録したとき | 「質問」画面であなたのキーを使うため。暗号化して保存します |
| あなたに発行された API キーの名前と日付 | 運営者が発行したとき | API の提供 |

本サービスは広告を表示せず、アクセス解析ツールも使いません。Cookie は2つだけです。ログイン状態を保つためのものと、ログインの途中だけ使う一時的なものです。表示の設定、保存した分析、マイ系統はあなたのブラウザに保存され、運営者のサーバーには保存されません。

## 保存する期間

| 情報 | 期間 |
|---|---|
| アカウント、保存したビュー、「質問」画面の調査、登録した LLM の API キー | あなたが削除するまで |
| あなたに発行された API キー（取り消したものを含む） | アカウントを削除するまで |
| セッション | 最長30日 |
| ログインの記録 | 25か月 |
| 日ごとの利用回数 | 25か月 |
| アカウントと結びつけない「質問」画面の質問文 | 90日 |
| 運営者が質問の候補に採用した「質問」画面の質問文（よく使われる質問を自動で採用する場合を含みます） | 候補として使う間 |
| 管理者の操作記録（あなたのアカウントに対する操作を含む） | 400日 |

期間を過ぎた記録は、毎日自動で削除します。

## 外部の委託先への送信

法令にもとづく場合を除き、あなたの同意なく個人情報を第三者に提供しません。本サービスの運営のため、次の委託先に取り扱いを任せています。

- **サーバーとデータベース**：本サービスは現在、一般には公開していません。公開するときは、その前に委託先の名称と所在国をこのページに記載します。
- **Google LLC、GitHub, Inc.**：ログイン（あなたが選んだほうだけ）
- **Google LLC（Gemini API）、OpenAI, L.L.C.**：「質問」画面の質問が LLM で答える段階に進んだとき、質問文と、答えに必要な集計データを送ります。あなた自身の API キーを登録している場合は、そのキーの提供元に送ります。

ログインと LLM の委託先は、いずれも米国の企業です。米国の個人情報の保護の制度は、個人情報保護委員会が公表している「外国における個人情報の保護に関する制度等の調査」で確認できます。

## あなたができること

- **データのダウンロード：** アカウント画面から、本サービスが持っているあなたのデータを JSON 形式でダウンロードできます。あなたあての招待やあなたが使った招待と、あなたが管理者として行った操作の日時と種類（記録がある場合は、IP アドレスとブラウザの種類も）を含みます。それ以外の管理者の操作記録（あなたのアカウントに対する操作を含む）は含まれないので、その開示は上の連絡先で受け付けます。
- **アカウントの削除：** アカウント画面から、アカウントを削除できます。削除すると、上の表のあなたの情報はすぐに消えます。管理者の操作記録に残るあなたのメールアドレスと名前は伏せ字にします。アカウントと結びつけない「質問」画面の質問文だけは、90日たつまで残ります。運営者が質問の候補に採用したもの（よく使われる質問を自動で採用する場合を含みます）は、候補として使う間残ります。
- **その他の依頼：** 開示、訂正、利用の停止などのご依頼は、上の連絡先で受け付けます。

## 安全のための取り組み

- 通信は HTTPS で暗号化しています。
- ログインは Google と GitHub に任せており、利用者のパスワードを預かりません。
- 登録された LLM の API キーは暗号化して保存しています。
- 個人情報を見られるのは運営者だけです。
- サーバーとデータベースを置く国は、委託先とあわせて「外部の委託先への送信」に記載します。
