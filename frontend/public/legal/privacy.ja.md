# プライバシーポリシー

最終更新日：2026年11月17日

本サービスの画面は、ログインしなくてもすべて使えます。ログインできるのは、本サービスの管理者だけです。

## 集める情報と使いみち

### 本サービスを使うすべての人

| 情報 | 集めるとき | 使いみち |
|---|---|---|
| 質問文（だれの質問かは記録しません） | 調査ノートや API で質問したとき | 質問に答えるため、回答の品質の改善 |
| 管理者用のパスワードでのログインの記録（日時、IP アドレス、ブラウザの種類。失敗したときは、入力されたユーザー名を元に戻せない形に変えた値も） | 管理者用のパスワードでログインしようとしたとき（失敗したときを含みます） | 管理者のアカウントへの不正なログインの検知と調査 |

質問文には、個人情報を書かないでください。管理者用のパスワードでのログインでは、入力されたパスワードは記録しません。

このほかに、次のように扱います。

- **1日のアクセス数：** 画面や API の種類と事業者ごとに、1日のアクセス数とエラー数を数えています。この数には、だれのアクセスかを示す情報（IP アドレス、Cookie など）を含みません。
- **アクセスの制限：** 過度なアクセスを制限するため、サーバーは IP アドレスごとのアクセス数を、1分ほどメモリ上で数えます。この IP アドレスは保存しません。
- **サーバーのログ：** アクセスごとに、日時、アクセス先の URL（「?」以降の検索条件は含みません）、結果、処理にかかった時間を記録します。IP アドレスとブラウザの種類は記録しません。管理者がログインしているときは、管理者のアカウントの番号も記録します。
- **管理者でない人のログイン：** Google または GitHub でログインしようとした人が管理者でないときは、ログインを断ります。管理者かどうかを確かめるために、ログイン先からメールアドレスを受け取りますが、保存しません。記録するのは、日時、ログインの方法、断った理由だけです。

### 管理者

| 情報 | 集めるとき | 使いみち |
|---|---|---|
| メールアドレス、表示名、アイコン画像の URL | Google または GitHub でログインしたとき | 本人の確認、アカウントの表示 |
| ログインと主な操作の記録（日時、ログインの方法や操作の種類、IP アドレス、ブラウザの種類） | ログインとログアウトのとき、アカウントや事業者を管理する操作をしたとき | 不正利用の調査、セキュリティの維持 |
| セッション（IP アドレス、ブラウザの種類、最後に使った日時） | ログインしている間 | ログイン状態の維持、ほかの端末からのログアウト |
| 日ごとの利用回数（画面や API の種類ごとの回数とエラー数、見ていた事業者） | ログインしている間 | 利用状況の把握、負荷の管理 |
| 調査ノートに記録した調査 | 保存したとき | その機能を提供するため |
| 管理者の操作記録（日時、操作の種類と対象、変更の前と後、IP アドレス） | 管理者として操作したとき | 操作の記録、セキュリティの維持 |

管理者がログインすると、そのブラウザに保存されていた調査ノートの調査は、管理者のアカウントに移します。

### ブラウザに保存するもの

表示の設定、保存したビュー、保存した分析、マイ系統、最後に使ったフィルター、ログインせずに調査ノートに記録した調査は、あなたのブラウザに保存されます。運営者のサーバーには保存しません。

### Cookie

本サービスは広告を表示せず、アクセス解析ツールも使いません。Cookie は管理者のログインにだけ使います。ログイン状態を保つためのもの（最長30日）と、ログインの途中だけ使う一時的なもの2つ（最長10分）です。ログインしようとしなければ、Cookie は使いません。

## 保存する期間

| 情報 | 期間 |
|---|---|
| 質問文 | 最後に質問されてから90日 |
| ログインと主な操作の記録（管理者用のパスワードでのログインの失敗を含みます） | 25か月 |
| 管理者のアカウント | アカウントを削除するまで |
| 管理者が調査ノートに記録した調査 | 管理者が削除するか、アカウントを削除するまで |
| セッション | 最長30日 |
| 管理者の日ごとの利用回数 | 25か月 |
| 管理者の操作記録 | 400日 |

期間を過ぎた記録は、毎日自動で削除します。だれのアクセスかを示す情報を含まない1日のアクセス数は、期間を決めずに保存します。

## 外部の委託先への送信

法令にもとづく場合を除き、あなたの同意なく個人情報を第三者に提供しません。本サービスの運営のため、次の委託先に取り扱いを任せています。

- **サーバーとデータベース**：本サービスは現在、一般には公開していません。公開するときは、その前に委託先の名称と所在国をこのページに記載します。
- **Google LLC、GitHub, Inc.**：管理者のログイン（管理者が選んだほうだけ）
- **Google LLC（Gemini API）、OpenAI, L.L.C.**：質問に LLM で答えるとき（調査ノートで結果について質問したときを含みます）、質問文と、答えに必要な集計データを送ります。

ログインと LLM の委託先は、いずれも米国の企業です。米国の個人情報の保護の制度は、個人情報保護委員会が公表している「外国における個人情報の保護に関する制度等の調査」で確認できます。

## ブラウザが直接読み込むもの

地図の画像、地図の文字の字形、画面のフォントは、あなたのブラウザが提供元から直接読み込みます。ふつうのウェブページを表示するときと同じく、提供元にはあなたの IP アドレスとブラウザの種類が届きます。

- **地図の画像**：国土地理院（地理院タイル）、OpenStreetMap Foundation（OpenStreetMap のタイル）。選んだ地図の種類によって、どちらか一方です。
- **地図の文字の字形**：MapLibre のデモ用サーバー（demotiles.maplibre.org）
- **フォント**：Google LLC（Google Fonts）

## あなたができること

- **ブラウザに保存したものの削除：** ブラウザでこのサイトのデータを消すと、「ブラウザに保存するもの」に書いたものはすべて消えます。
- **質問文：** 質問文はだれの質問かを記録しないので、特定の人の質問を探すことも、削除することもできません。
- **管理者のアカウントの削除：** 管理者のアカウントは、運営者が削除します。削除すると、メールアドレス、表示名、アイコン画像を消し、セッション、Google や GitHub との連携、調査ノートに記録した調査を削除します。ログインと主な操作の記録、管理者の操作記録は、上の期間が過ぎるまで残ります。
- **その他の依頼：** 開示、訂正、利用の停止などのご依頼は、上の連絡先で受け付けます。

## 安全のための取り組み

- 通信は HTTPS で暗号化しています。
- 管理者のログインは、Google と GitHub に任せています。本サービスが持つパスワードは管理者用のパスワードだけで、元に戻せない形（ハッシュ）で保存しています。
- 個人情報を見られるのは、運営者と、運営者が任命した管理者だけです。
- サーバーとデータベースを置く国は、委託先とあわせて「外部の委託先への送信」に記載します。
