# プライバシーポリシー

最終更新日：2026年9月30日

Transit Delay App（以下「本サービス」）は、TripAndCode が個人で運営しています。このページでは、本サービスが扱うあなたの情報と、その扱い方を説明します。

## 運営者

- 名称：TripAndCode（個人による運営）
- 氏名と住所：求めに応じて、遅滞なくお知らせします。
- 連絡先：[お問い合わせフォーム]({{CONTACT_FORM_URL}})。返信は本サービス専用のメールアドレスから送ります。バグや要望は [GitHub Issues](https://github.com/TripAndCode/transit-app/issues) でも受け付けますが、Issues は公開されるので、個人情報は書かないでください。

## 集める情報と使いみち

| 情報 | 集めるとき | 使いみち |
|---|---|---|
| メールアドレス、表示名、アイコン画像の URL | Google または GitHub でサインインしたとき | 本人の確認、アカウントの表示 |
| サインインの記録（日時、方法、IP アドレス、ブラウザの種類） | サインインとサインアウトのとき | 不正利用の調査、セキュリティの維持 |
| セッション（IP アドレス、ブラウザの種類、最後に使った日時） | 使っている間 | サインイン状態の維持、ほかの端末からのサインアウト |
| 日ごとの利用回数（画面や API の種類ごとの回数とエラー数、見ていた事業者） | 使っている間 | 利用状況の把握、負荷の管理、料金の検討 |
| 保存した条件、Ask の会話 | あなたが保存したとき | その機能を提供するため |
| Ask の質問文（アカウントと結びつけない形） | Ask を使ったとき | 回答の品質の改善 |
| あなたが登録した LLM の API キー | 登録したとき | Ask であなたのキーを使うため。暗号化して保存します |
| あなたに発行された API キーの名前と日付 | 運営者が発行したとき | API の提供 |

本サービスは広告を表示せず、アクセス解析ツールも使いません。Cookie は2つだけです。サインイン状態を保つためのものと、サインインの途中だけ使う一時的なものです。表示の設定や保存した分析はあなたのブラウザに保存され、運営者のサーバーには保存されません。

## 保存する期間

| 情報 | 期間 |
|---|---|
| アカウント、保存した条件、Ask の会話、登録した LLM の API キー | あなたが削除するまで |
| あなたに発行された API キー（取り消したものを含む） | アカウントを削除するまで |
| セッション | 最長30日 |
| サインインの記録 | 25か月 |
| 日ごとの利用回数 | 25か月 |
| アカウントと結びつけない Ask の質問文 | 90日 |
| 管理者の操作記録（あなたのアカウントに対する操作を含む） | 400日 |

期間を過ぎた記録は、毎日自動で削除します。

## 外部の事業者への送信

法令にもとづく場合を除き、あなたの同意なく個人情報を第三者に提供しません。本サービスの運営のため、次の事業者に取り扱いを任せています。いずれも米国の事業者です。

- **Railway Corporation**：サーバーとデータベース
- **Google LLC、GitHub, Inc.**：サインイン（あなたが選んだほうだけ）
- **Google LLC（Gemini API）、OpenAI, L.L.C.**：Ask の質問が LLM で答える段階に進んだとき、質問文と、答えに必要な集計データを送ります。あなた自身の API キーを登録している場合は、そのキーの事業者に送ります。

米国の個人情報の保護の制度は、個人情報保護委員会が公表している「外国における個人情報の保護に関する制度等の調査」で確認できます。

## あなたができること

- **データのダウンロード：** アカウント画面から、本サービスが持っているあなたのデータを JSON 形式でダウンロードできます。
- **アカウントの削除：** アカウント画面から、アカウントを削除できます。削除すると、上の表のあなたの情報はすぐに消えます。管理者の操作記録に残るあなたのメールアドレスと名前は伏せ字にします。アカウントと結びつけない Ask の質問文だけは、90日たつまで残ります。
- **そのほかの依頼：** 開示、訂正、利用の停止などのご依頼は、上の連絡先で受け付けます。

## 安全のための取り組み

- 通信は HTTPS で暗号化しています。
- サインインは Google と GitHub に任せており、パスワードを預かりません。
- 登録された LLM の API キーは暗号化して保存しています。
- 個人情報を見られるのは運営者だけです。
- 本サービスは、米国の事業者（Railway Corporation）が提供するサーバーで動いています。
